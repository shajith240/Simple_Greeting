# Greeting Function

A simple JavaScript project that creates personalized greetings based on the time of day.

## Features

- Formats a first name and last name.
- Returns a greeting for the morning, afternoon, or evening.
- Combines the greeting and name into one message.

## Project Structure

```text
greeting_function/
├── main.js
└── readme.md
```

## How to Run

1. Open a terminal in this folder.
2. Run the JavaScript file with Node.js:

```bash
node main.js
```

## Example Output

```text
Good morning, Shajith  Bathina
Good afternoon, Vijay  Banoth
Good evening, Dinesh  Yeturi
```

## Functions

### `formatName(firstName, lastName)`

Combines a first name and last name.

### `getGreeting(timeOfDay)`

Returns a greeting based on the supplied time of day.

### `createGreeting(firstName, lastName, timeOfDay)`

Creates a complete personalized greeting.
